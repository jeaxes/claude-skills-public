# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub private vulnerability reporting: open the repository's "Security" tab and choose "Report a vulnerability". Do not open a public issue for security problems.

Most skills here come from upstream collections. If the issue is in an imported skill, say which skill and file are affected; the fix may also need to go to the upstream project.

## Using the skills

Skills contain instructions and, in some cases, scripts that an assistant may run. Read a skill and its scripts before installing it, especially the security-testing skills, which are intended only for systems you are authorized to test.
